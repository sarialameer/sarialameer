# Sari G. Al-Ameer

Astronomy & Physics BSc, King Abdulaziz University.

I work on space weather and solar-terrestrial physics, and on the instruments that measure them. At the moment that means a VLF radio station for solar flares, orbit calculations with SGP4 and J2, cosmic ray muon detection, a self-hosted NAS and home server on NixOS, and a USB password device based on a Pico 2.
